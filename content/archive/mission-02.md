> *「ようこそ、我がベルベットルームへ。」*

---

## 青の間

毎夜、夢の中で訪れる**青い部屋**——ベルベットルーム。

そこには長い鼻の老人**イゴール**と、その助手たちが待っている。

### ペルソナ合体の儀式

```javascript
function personaFusion(a, b) {
  const arcana = calculateArcana(a.arcana, b.arcana);
  const skills = inheritSkills(a.skills, b.skills);
  return { name: generateName(arcana), level: Math.floor((a.level+b.level)/2)+1, arcana, skills };
}
```

### アルカナの種類

- **愚者（The Fool）** — 無限の可能性
- **魔術師（The Magician）** — 意志と技術
- **女教皇（The High Priestess）** — 直感と神秘
- **皇帝（The Emperor）** — 統治と秩序
- **恋人（The Lovers）** — 選択と絆

> *「契約は履行されねばならない。それがこの部屋の掟だ。」*
