## 基本戦術

### 1. アンブッシュ（先制攻撃）

シャドウの背後から接近し、**不意を突く**。先制を取れれば戦闘の勝率は格段に上がる。

### 2. 属性相性

| 属性 | 弱点を突ける相手 |
|------|----------------|
| 物理 ⚔️ | 魔法使い系 |
| 火炎 🔥 | 氷結系 |
| 氷結 ❄️ | 火炎系 |
| 電撃 ⚡ | 疾風系 |
| 疾風 🌪️ | 電撃系 |

### 3. バトンタッチ

```
1ターン目の理想形：
  Joker → 弱点突く → ダウン！
  → バトンタッチ → Skull
  → 別の敵の弱点 → ダウン！
  → ホールドアップ → 総攻撃！！
```
