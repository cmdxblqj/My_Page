# Verdant Codex · 翠玉文庫

> A Persona 5 × Pop Art inspired markdown reader with green aesthetics.

---

## How to Use

1. Open `green-archive-reader.html` in your browser
2. Browse the built-in codex entries (Persona 5 themed articles)
3. Click any card to open the markdown reader
4. Press `Esc` or click the ✕ button to close the reader

## Adding Your Own Content

Simply drop any `.md` file into this folder. The page will automatically discover and display it in the codex list.

Supported filenames include:
- `README.md`
- `notes.md`
- `article.md`
- `guide.md`
- Any file ending in `.md`

## Design

- **Style**: Pop Art × Persona 5
- **Palette**: Emerald green, neon lime, gold, black
- **Fonts**: Bebas Neue, DM Sans, Fredoka, Noto Sans SC
- **Features**: Markdown rendering, scroll effects, sparkle cursor, comic panel layout
