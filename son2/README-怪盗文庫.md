# Phantom Archive · 怪盗文庫 — 使用说明

## 如何添加/编写文章

文章数据存放在 `blue-article-reader.html` 文件底部的 JavaScript `STATIC_ARTICLES` 数组中。每篇文章是一个对象，字段如下：

### 文章对象字段说明

```javascript
{
  id: 'mission-01',           // 唯一标识符（英文，kebab-case）
  title: '心の怪盗団 · 最初の任務',  // 文章标题（显示在按钮和阅读器顶部）
  date: '2026.06.01',         // 日期（显示在按钮左上角）
  time: '14:30',              // 时间（显示在日期旁边）
  cover: '🎭',                // 封面图标（推荐使用 emoji，也支持任意文字）
  tags: ['使命', '怪盗'],      // 标签数组（显示为 #标签 样式）
  excerpt: '最初のパレスへの潜入…', // 摘要（按钮上显示的简介，建议 30 字以内）
  content: ` ... `,           // Markdown 正文（见下方详细说明）
}
```

### 各字段详细写法

#### `id` — 唯一标识
- 格式：英文小写 + 连字符，如 `'my-first-post'`
- 用于：API 路由匹配、按钮高亮状态追踪
- ⚠️ 不可重复

#### `title` — 标题
- 显示位置：按钮主体文字 + 阅读器顶部大标题
- 建议长度：10–30 字
- 支持中文、日文、英文混排
- 示例：`'ベルベットルームの秘密'`

#### `date` & `time` — 日期与时间
- `date` 格式建议：`YYYY.MM.DD`（如 `'2026.06.01'`）
- `time` 格式建议：`HH:MM`（如 `'14:30'`）
- 按钮上以等宽字体显示在左上角

#### `cover` — 封面图标
- 单个 **emoji** 效果最佳（渲染为 52×52 方块）
- 示例：
  - `'🎭'` — 面具（怪盗主题）
  - `'🟦'` — 蓝色方块
  - `'🐱'` — 猫（モルガナ）
  - `'🤝'` — 握手（コープ/羁绊）
- 也可以用 1-2 个中文/日文字符，如 `'怪'`

#### `tags` — 标签
- 字符串数组，如 `['使命', '怪盗']`
- 按钮上显示为 `#使命` `#怪盗` 小药丸标签
- 阅读器标题下方也会显示
- 建议每篇 1-3 个标签

#### `excerpt` — 摘要
- 按钮上标题下方的灰色简介文字
- 最多显示 **2 行**（超出自动截断）
- 建议 20–50 字

#### `content` — Markdown 正文
- 使用 ES6 模板字符串（反引号包裹），支持多行
- 支持完整 **GFM (GitHub Flavored Markdown)** 语法
- 详见下方「Markdown 写作指南」

## Markdown 写作指南

阅读器使用 [marked.js](https://marked.js.org/) 渲染，支持以下语法并有 P5 风格定制样式。

### 标题

```markdown
# 一级标题（带 ◆ 菱形前缀，蓝色大字，底部边框线）
## 二级标题（带 ◆ 小菱形前缀，天蓝色）
### 三级标题（天蓝色，无装饰）
#### 四级标题（浅蓝色，无装饰）
```

> **写作提示**：一级标题适合章节名，二级标题适合小节名。

### 文本样式

```markdown
**粗体**           → 渲染为天蓝色加粗
*斜体*             → 渲染为淡金色斜体
~~删除线~~         → 渲染为半透明删除线
> 引用块           → 蓝色左边框 + 引号水印背景
```

### 链接

```markdown
[链接文字](https://example.com)  → 蓝色下划线，hover 变天蓝
```

### 列表

```markdown
- 无序列表项        → 蓝色菱形 ◆ marker
   - 嵌套项         → 空心菱形 ◇ marker

1. 有序列表项       → 蓝色数字 marker
2. 第二项
```

> 列表支持 emoji + 加粗混排，如：`- 🔹 **重点项** — 说明文字`

### 代码

````markdown
`行内代码`          → 深蓝底 + 等宽字体

```javascript       → 代码块：黑色底 + 顶部蓝色渐变线
const x = 1;        → JetBrains Mono 等宽字体
```
````

### 表格

```markdown
| 列A | 列B | 列C |
|-----|-----|-----|
| 数据 | 数据 | 数据 |
```

渲染效果：蓝色表头 + hover 行高亮 + 底部细线分隔。

### 分割线

```markdown
---   → 蓝色虚线渐变分割线
```

### 图片

```markdown
![alt](url)  → 蓝色边框 + 圆角
```

## 添加新文章：分步教程

### 方法一：直接编辑 STATIC_ARTICLES（推荐）

1. 用任意代码编辑器打开 `blue-article-reader.html`
2. 搜索 `STATIC_ARTICLES`（约在第 750 行）
3. 在数组末尾添加新对象：

```javascript
{
  id: 'my-new-post',
  title: '你的文章标题',
  date: '2026.06.10',
  time: '10:30',
  cover: '📝',
  tags: ['标签1', '标签2'],
  excerpt: '这里写文章的一句话概要，会在按钮上显示。',
  content: `
# 文章大标题

## 第一节

这里是正文内容，支持 **Markdown** 语法。

- 列表项一
- 列表项二

> 引用示例

| 表头A | 表头B |
|-------|-------|
| 数据1 | 数据2 |

\`\`\`javascript
console.log('代码示例');
\`\`\`

---
*完*
`,
},
```

4. 保存文件，刷新浏览器即可看到新文章按钮（带交错淡入动画）

### 方法二：连接后端 API

1. 确保后端运行在 `http://localhost:3000`
2. 在代码中搜索 `CONFIG` 对象（脚本区顶部）
3. 修改：

```javascript
const CONFIG = {
  API_BASE_URL: 'http://localhost:3000/api',
  USE_API: true,   // ← 改为 true
  // ...
};
```

4. API 接口约定：

```
GET  /api/articles          → 返回文章数组（字段同上）
GET  /api/articles/:id      → 返回单篇文章对象
```

5. 两个接口均需返回与 `STATIC_ARTICLES` 相同结构的 JSON
6. API 不可用时自动 fallback 到静态数据

## 文章按钮排列说明

- 按钮**纵向排列**，间距 1rem
- 每篇自带**交错入场动画**（0.5s→1.0s，间隔 0.1s）
- hover 时：上浮 + 阴影扩散 + 蓝色边框发光 + 箭头 `▶` 淡入
- 选中态：蓝色霓虹边框呼吸灯
- 滚动时按钮有**连续淡入淡出**效果（viewport 中间最亮，边缘渐隐）

| 端口 | 用途 | 状态 |
|------|------|------|
| `3000` | API 后端 | 预留（STANDBY） |

页面右下角有端口状态指示器，设为 `USE_API = true` 后会显示连接状态。

## 技术栈

- **marked.js** — Markdown 渲染（CDN 引入）
- **Google Fonts** — Bebas Neue / DM Sans / Fredoka / Noto Sans SC / JetBrains Mono
- **纯 HTML/CSS/JS** — 无构建工具依赖，浏览器直接打开即可使用
