# 前端网页切换对角线碰撞与水面过渡动画指导手册



---

## 1. 动画需求概述
在 1920×1080 分辨率的网页切换过程中，实现一个具有物理碰撞感和流体过渡效果的转场动画。核心元素包括两张 PNG 图片的对角线垂直碰撞，以及一个高饱和度纯色（`#f3a90b`）水面波动界面的覆盖与消退。动画需支持异步加载等待状态。

---

## 2. 核心参数与坐标系定义
*   **视口尺寸**：固定或基准尺寸 1920px (宽) × 1080px (高)。
*   **中心点 (Center)**：`(960, 540)`。
*   **主对角线向量**：从左上 `(0, 0)` 到右下 `(1920, 1080)`，方向向量可简化为 $\vec{d} = (16, 9)$。
*   **垂直运动方向向量**：垂直于 $\vec{d}$ 的向量为 $\vec{v_1} = (9, -16)$ 和 $\vec{v_2} = (-9, 16)$。
    *   `first.png` (左下进入)：沿 $\vec{v_1}$ 方向的反方向起始，向中心点移动。
    *   `second.png` (右上进入)：沿 $\vec{v_2}$ 方向的反方向起始，向中心点移动。
*   **水面颜色**：`#f3a90b` (高饱和度橙色)。

---

## 3. 动画时间轴梳理 (Timeline)

整个动画由一个主控时间轴管理，分为四个关键阶段：

### 阶段一：进入与生长 (0.0s - 0.9s)
*   **图片运动**：`first.png` 和 `second.png` 同时从屏幕外（分别从左下和右上方向）沿垂直于对角线的轨迹，向中心点 `(960, 540)` 加速移动。建议使用 `ease-out` 或自定义 `cubic-bezier` 缓动，模拟物体受引力加速的效果。
*   **水面生长**：纯色界面 (`#f3a90b`) 从左上角 `(0, 0)` 开始向右下角 `(1920, 1080)` 扩展。扩展的**最前沿**（右下侧边缘）需呈现平滑的波动水面效果，边缘后方为绝对纯色，无任何纹理细节。

### 阶段二：中心碰撞 (0.9s - 1.0s)
*   **碰撞触发**：当两张图片的中心点重合于 `(960, 540)` 时触发。
*   **碰撞表现**：模拟弹性小球碰撞。
    1.  **挤压 (Squash)**：接触瞬间，图片沿运动方向轻微压扁（如 `scaleX: 1.15, scaleY: 0.85`）。
    2.  **回弹 (Stretch & Rebound)**：快速恢复并产生极微小的反向分离（震荡），幅度迅速衰减。
    3.  **约束**：整个碰撞形变与震荡过程必须紧凑，总震荡周期不超过 1.5 次，在 1.0s 时完全静止于中心接触状态。
*   **水面覆盖**：在 1.0s 时，水面波动前沿恰好抵达右下角 `(1920, 1080)`，纯色层 100% 覆盖视口，完成对底层网页切换的视觉遮挡。

### 阶段三：加载等待 (Hold State, 1.0s - N s)
*   **状态保持**：如果下一个网页的资源（DOM、图片、数据）尚未加载完毕，动画时间轴在此处**暂停 (Pause)**。
*   **视觉表现**：画面保持两张图片在中心轻微接触的状态，全屏被 `#f3a90b` 纯色覆盖。水面波动前沿可保持极其微弱的“呼吸感”波动，避免画面死板，但不发生位移。

### 阶段四：分离与消退 (加载完成后，耗时 1.0s)
*   **触发条件**：接收到“新页面加载完成”的全局事件。
*   **图片分离**：两张图片从中心点 `(960, 540)` 沿原进入轨迹**原路返回**，退出屏幕可视区域。缓动函数切换为 `ease-in`，模拟离开时的加速感。
*   **水面消退**：纯色界面开始消失。根据需求，消失动作**从左上角开始，最终在右下角结束**。
    *   *实现逻辑*：一个带有波动边缘的“透明窗口”从左上角 `(0, 0)` 向右下角 `(1920, 1080)` 扫描推进。波动边缘扫过的地方，`#f3a90b` 纯色层变为透明，逐渐露出已加载好的新网页。当波动边缘抵达右下角时，过渡层完全消失。

## 4. 关键技术栈推荐

为实现高性能、高可控性的动画，推荐以下技术组合：

1.  **核心动画引擎：GSAP (GreenSock Animation Platform)**
    *   **理由**：处理复杂的多元素同步、精确的时间轴控制（尤其是 `pause` 和 `resume` 等待加载状态）、以及高级缓动函数（如 `Elastic.easeOut` 用于碰撞）的行业标准。其 `Timeline` 功能是管理此场景的不二之选。
2.  **水面波动效果：SVG Filters (`feTurbulence` + `feDisplacementMap`) + CSS Masking**
    *   **理由**：需求明确指出“不需要任何细节，只需要最前端有波动效果，其余纯色”。使用 WebGL (Three.js/PixiJS) 属于过度设计且增加包体积。
    *   **方案**：创建一个全屏的 `#f3a90b` `div`。使用 CSS `clip-path` 或 `mask-image` 结合一个动态生成的 SVG 波浪路径。通过 GSAP 动画化 SVG 路径的 `d` 属性或控制 `feTurbulence` 的 `baseFrequency`，实现边缘的平滑波动和从左上到右下的位移动画。
3.  **框架与状态管理：React (Next.js) / Vue (Nuxt.js) + 路由守卫**
    *   **理由**：需要精确拦截路由切换。在 `beforeRouteLeave` 或 Next.js 的 `App Router` 过渡事件中触发“阶段一”，在 `onLoad` 或数据获取完成后触发“阶段四”。
4.  **性能优化：CSS `will-change` 与 GPU 加速**
    *   **理由**：图片的位移和缩放必须使用 `transform: translate3d() scale3d()`，避免触发重排 (Reflow)。

## 5. 核心视觉效果实现指导

### 5.1 垂直对角线运动的数学映射
不要使用简单的 `top/left` 动画。应预先计算好起始坐标：
*   设屏幕外安全距离为 $D$ (例如 1500px)。
*   `first.png` 起始位置：`x = 960 - D * (9 / \sqrt{9^2 + 16^2})`, `y = 540 + D * (16 / \sqrt{9^2 + 16^2})`。
*   使用 GSAP 的 `x` 和 `y` 属性直接动画到 `0` (相对于中心点的偏移量)。

### 5.2 小球碰撞感 (Squash and Stretch)
*   避免使用简单的震动 (Shake)。真正的碰撞感来源于**体积守恒的形变**。
*   指导动画师或开发者设置关键帧：在接触前 0.05s 开始轻微拉伸（沿运动轴），接触瞬间 (0.9s) 垂直于运动轴压扁，随后在 0.05s 内快速回弹并伴随 1 次极小振幅的反向形变，最后锁定为 `scale(1, 1)`。

### 5.3 纯色水面波动边缘
*   **进入时**：波动边缘是纯色区域的“前锋”。可以使用一个宽度/高度动态增加的容器，其右下角边界应用 SVG 波浪滤镜。
*   **消失时**：注意逻辑反转。不是纯色块缩小，而是**透明区域扩大**。可以使用一个覆盖全屏的 `#f3a90b` 层，其 `mask` 是一个从左上向右下移动的、边缘呈波浪形的多边形。多边形内部为 `transparent` (透出下层)，外部为 `black` (保留纯色)。

## 6. 状态管理与性能优化建议

1.  **加载等待的鲁棒性**：
    *   必须设置一个最大超时时间 (Timeout，例如 3-5 秒)。如果新页面因网络问题未能加载，应强制结束等待，执行“阶段四”的退出动画，或回退到原页面，避免用户面对无限期的静止画面。
2.  **资源预加载**：
    *   `first.png` 和 `second.png` 必须作为关键资源在初始页面加载时预加载 (Preload)，确保切换时不会出现图片闪烁或延迟出现。
3.  **响应式兜底 (Responsive Fallback)**：
    *   虽然基准是 1920×1080，但需考虑非 16:9 屏幕。建议使用 `vmin`/`vmax` 或 JS 动态计算中心点和向量比例，确保在非标准分辨率下，图片依然能准确从“视觉上的左下角/右上角”垂直于对角线进入中心。
4.  **无障碍访问 (a11y)**：
    *   检测用户的 `prefers-reduced-motion` 媒体查询。如果用户开启了减弱动态效果，应跳过复杂的碰撞和水面波动，直接执行简单的淡入淡出 (Fade) 过渡。
